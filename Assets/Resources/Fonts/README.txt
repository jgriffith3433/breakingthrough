Fonts for every menu, HUD and dialogue box (UiSkin.Font(role)).
Fraunces-SemiBold.ttf: Fraunces (SIL OFL 1.1, Fraunces-OFL.txt), instanced from the variable font at wght 600, opsz 36, SOFT 0, WONK 0, subset to Latin + punctuation.
SpecialElite-Regular.ttf: Special Elite (Apache 2.0 on Google Fonts, SpecialElite-LICENSE.txt), subset to Latin + punctuation.
